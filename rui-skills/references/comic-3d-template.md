# 3D漫剧提示词模板

漫剧仅制作3D动画或风格化三维CG。本文件控制漫剧成稿格式；排镜判断继续执行[叙事设计](narrative-camera-design.md)，材质与光影执行[模式规则](mode-profiles.md)。适用于完整分镜、独立提交片段及局部镜头修改；用户只给一句或一段时只处理该范围。

## 输出结构

每组先写“统一提示词”：本组3D风格、实际人物/场景参考、时间地点、模型与材质一致性、依[光影设计](lighting-design.md)确定的环境光方向、软硬、明暗与冷暖、共用声音和字幕要求，以及本组总时长和估算/实测状态。参考已提供时简写辨识要点，不重新设计外貌服装。人物具体站位、手位及变化写进对应镜头。每组保持独立可用，不写“同上”代替必要内容。

随后按以下七个字段逐镜输出，每项独立成段；标题保留组内起止和单镜时长。下列方括号是写作占位符，成稿替换为本镜的具体内容。

```text
二、分镜头正文

镜头 1（[起点]-[终点] 秒，时长[数值]秒）
画面：[景别、机位角度、实际时间地点与核心画面内容；本镜必要的造型、空间和人物关系]
镜头：[虚拟镜头焦段或类型、景深、焦点位置；有移焦时明确起止对象]
运镜：[固定或具体运动；运动的触发、起始取景、路径与速度、结束取景]
角色动作 & 表情：[实际姓名、已有动作的起点/过程/结束状态、眼神与表情变化、对象及必要后景状态]
台词：[角色实名、声音来源、情绪/语气及逐字台词；无台词时注明无台词，并列有依据的环境声或动作声]
约束：[本镜适用的声音、音乐、字幕、身份、空间或道具连续性要求]
特效 & 转场：[已有特效的具体过程或“无额外特效”；本镜实际切换/衔接方式，末镜写实际收尾]
```

后续镜头使用同样七项。焦段或虚拟镜头类型按本镜设计填写，未锁定时不强行添加精确焦距、光圈或实拍机身；焦点必须指向具体对象。没有台词不等于必须新增声效，没有特效不等于必须添加粒子。当前镜头是独立修改范围的末镜但仍接后文时，保留其已知承接，不擅自改成整段结束。

逐字保留原始对白，台词的人设匹配通过语气、节奏和表演落实，不改写原句。已有内心独白标明画外内心声，不驱动画内口型；材料没有时不新增。跨镜连续台词可以按原顺序分配原句片段，合并后须与原句逐字一致，不插入新词或重复播放；说明声源与承接关系。

## 切镜按剧情灵活安排

以下是检查观看重点和切点的条件，不是逐句拆镜或固定镜数的命令。超过10字的台词只触发一次节奏检查，不按字数强制切镜，也不设每镜最多10字。完整台词、自然语速、情绪及动作完成优先。

| 检查情境 | 决策方式 |
| --- | --- |
| 显著情绪转变或情绪积累 | 确保转折发生时的眼神、表情和已有回应可读；比较同镜持续观察、移焦与切换取景，不把每个情绪词自动变成独立特写。 |
| 复杂动作 | 梳理材料已有的准备、执行、结果及回应，按接触和因果组织；不强制三镜，不为凑准备或反应新增动作。 |
| 人物进出、位置或关系变化 | 核对主体、控制关系和观看对象；当前取景已清楚时可连续呈现，变化不可读时再切镜。 |
| 场景切换、时间跳跃或并行线 | 清楚区分新时空及镜头编号；需要过渡时使用材料已有画面或声音，不为凑1–2秒转场新增事件、空镜或地点。 |
| 说话与倾听 | 按信息和反应选择讲话者、听者或关系镜，保持对话轴线与视线；不机械循环“说话者→听者→说话者”。 |
| 景别、角度、焦点或运动变化 | 区分同一镜头内连续变化与真正剪切；推拉、摇移、升降及组合运动可以在一个镜头完成，不因状态变化自动中断。 |
| 关键道具、特效或强烈冲击 | 确保核心信息得到必要观看时间；是否独立成镜按叙事需要决定，不为特效展示添加剧情。 |

景别和运动应随信息与情绪变化，复核无任务的重复。增强张力时写出具体触发、路径、速度与落点；固定镜头仍可承担有张力的观察，不规定每镜必须运动。镜头切换不加速、截断对白或让人物等待摄影机。

## 3D表演与微动态

主体人物采用3D漫剧可读、较外放的表情与情绪反应，幅度随已有剧情和人物性格调节；材料中的克制、伪装与平静不改成持续夸张。场内其他人物保持自然的注意、呼吸和既有情绪状态，重要后景行为随剧情继续，不因主角镜头而冻结，也不为“活跃”新增抢戏动作。

按本镜需要从以下类别细化已经存在的表演，选用必要项即可，不在每镜堆满清单：

- **眼部与眉眼：**视线对象、聚焦、眯眼或眼睑变化、眉部张力、自然眨眼；有明确心理触发并符合角色模型。
- **嘴部与口型：**嘴角、唇部张力、下颌开合及与完整对白一致的口型；有声倾听者不跟讲话者对口型。
- **面部组合：**眉眼、嘴部及已有头部姿态协同呈现喜悦、惊讶、愤怒、悲伤、恐惧、掩饰等材料已有情绪，描述起因和转变过程。
- **呼吸与身体微动态：**呼吸起伏、已有姿态中的重心稳定和身体张力；吞咽、敲桌、点脚、舔唇、前倾或后仰等具体动作只在材料已有或用户明确要求时使用。

模板里的百分比、角度、毫米、Hz、眨眼频率和呼吸周期不作为全局参数，不逐镜套用。不把表情库当作新增动作或生理变色的来源；保持既有禁用生理变色表达情绪的规则。非人角色只使用其真实参考具备的器官和结构。

## 场景、光线与人数

保持同一角色的3D模型比例、造型、服装、材质、尺度与资产版本；透视、遮挡、接触和景深服务明确空间关系。环境已有光源决定所有人物的受光方向、软硬、冷暖和亮度，转身与位移时连续变化；不为单个人凭空添加追随补光、轮廓灯或独立光源。剧情已有发光物或能力按真实来源处理，不由模板自动添加。光影细化执行[光影设计与连续性](lighting-design.md)；当前受光与材质写入“画面”，已有转身、位移或遮挡导致的变化写入“角色动作 & 表情”，本镜必要的连续性限制写入“约束”，保持七字段。

尽量用单人或必要的双人取景减少无任务的多人同框；这只是构图偏好，不能删去实际在场角色、改变位置、漏掉接触或重要后景动作。关系和群体行为确需同框时保留所需人数，并维护画外人物的实际位置与声音。

## 成稿与导出检查

保持每组不超过30秒、可变时长、逐镜时间连续、原始对白完整和默认Word交付；局部修改直接给所需范围。逐镜检查七个字段均有本镜实际内容，特效及声效无依据时明确不添加，禁止遗留占位符或整套技巧菜单。

工程仍用 `mode: "comic"`，`style` 显式记录3D及实际已选美术风格；共享提示词写清3D模型、材质与环境光。编译引擎2.0.1及其字段结构未改，CLI导出仍为中间稿，不能声称程序已自动输出本七字段模板。助手在最终交付时整理本格式，清除旧中间稿中的二维默认措辞；文字与结构核对不代表实际配音、生图或视频验收。
