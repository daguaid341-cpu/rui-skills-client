# 特效与物理视觉表现

先区分材质和光影呈现、材料已有的物理事件、明确给出的虚构能力。普通生活场景不因使用本库而加入魔法、灾难、界面或变身。真人剧与漫剧共用来源、作用对象、空间与因果；具体质感按[模式](mode-profiles.md)执行，不用全局“禁CG”“禁3D”排除用户已选表现形式。

## 每项效果写清的过程

确认效果来源和附着对象、起点与方向、路径及速度、出现和发展、与现有身体或环境的作用、结束或消散。写明前后层、遮挡、尺度及需要读清的主体，最后核对末态如何承接。内部可简记这些要点，最终用本场实际内容合成自然句子，不新增协议字段或输出一套效果菜单。

| 维度 | 执行内容 |
| --- | --- |
| 身份与锚定 | 效果固定属于已给角色、身体部位、道具或空间位置；不能随镜漂移、改换宿主或生成重复角色。 |
| 材质与运动 | 区分固体、液体、气体、颗粒、布料和发光体，运动服从本场设定的力、重量、惯性与消散方式。非发光物不自动自发光。 |
| 光影与反应 | 自发光效果可成为光源，对已有表面产生方向合理的照亮与反射；保持曝光和暗部信息。非自发光物按环境受光，不为效果额外添加灯具。 |
| 规模与可读性 | 用已有角色、物体或空间关系呈现尺度；全景、远景可使用，不为比较大小添加楼宇、山体、群众或其他参照物。 |
| 复杂度与连续性 | 明确当前主效果和必要伴随层；只有确实发生的环境反应才保留。不设每镜一种、每组三种或每段一次高难效果的硬限额，过载时先优化层次和分镜，不删材料。 |

## 效果类型与选择条件

| 类型 | 具体设计关注点 |
| --- | --- |
| 光束、光斑、体积光、反射与折射 | 来源、传播方向、已有遮挡和介质明确；玻璃、金属、水面分别处理反光或透射。光束存在需符合本场空气或风格条件，不能为可见光束新增烟雾。 |
| 粒子、火星、烟尘、雾、毒雾与腐化 | 粒子出生处、疏密变化、轨迹、扩散及消失有区别，不无限匀速漂浮。毒性、腐化或伤害是剧情事实，不能由颜色擅自推断。 |
| 水、其他液体、食物与流体 | 来源、体量、路径、重力、湍流、泡沫、浑浊度及表面反射按实际物质选择；水不表现成整片蓝布。食物、容器和液体只有原材料已有时才出现。 |
| 天气、风、雨、雪、火与自然环境 | 强度、方向、遮挡、积聚和已给状态连续；不把夜景自动改成雨夜，不新增雷电、洪水、燃烧或湿身。 |
| 衣物、头发、毛发与附属结构 | 动作或已有外力引发的滞后、重量和回落连续，干湿、破损及毛发结束状态有依据；不凭空起风或改变服装。 |
| 金属、磁力、机械、装置与科技界面 | 部件、连接、组装先后、运动来源及反射一致；磁力和界面须已在剧情中。不得自动生成按钮、读数、文字、武器或不同装置。 |
| 能量、元素、音波、念力及武器附魔 | 明确来源、传播、作用目标与给定结果；光束、分支电弧、体积波动或附着层依已给能力选择，不由善恶固定配色或自动附赠爆炸。音波画面化须有表现依据。 |
| 形体、材质变化、进化、兽化与英雄变身 | 保持同一主体及转换前后身份，写清变化发生的部位、顺序与完成形态。瞬变只有材料明确时使用，不能把变身换成新角色瞬间替身。 |
| 召唤、契约、投影、幻影、分身与残影 | 先分清新实体、影像、反射还是轨迹；数量、身份、出现处和作用范围只取已有设定，不自动增加分身或召唤物。 |
| 时间、慢动作、停格、倒放与空间扭曲 | 区分剪辑表现与剧情能力。明确哪些元素静止、运动、逆行及例外，空间边界和遮挡怎样连续；不将普通慢放写成角色停止时间。帧率、快门与播放速度分别说明，实际播放时长另算。 |
| 撞击、碎裂、坍塌、爆炸与灾难 | 已有原因、接触、变形或裂纹、碎片与粉尘的先后清楚；不添加额外破坏、伤口或受害者。规模和余波只到材料给出的范围。 |
| 生物、巨物、巨型法相与大规模对决 | 维持给定体型、比例、关节、毛发、甲片和服装的分层运动；以既有空间和参照物说明尺度，保护攻击对象与核心动作的可读性。 |
| 日常、肖像、城市、自然与产品视觉 | 选择实际材质、光照、景深与构图即可，不把画面美化误作新增事件；不自动改成广告、补空镜或设计不存在的产品功能。 |

## 类型题材的使用边界

魔法、魔幻、玄幻、仙侠、神圣、未来战争、科技和超级英雄只是检索分类，不决定画面必有法阵、符文、翅膀、金光或粒子。尊重原材料的具体能力、道具及造型，保持同一设定跨镜稳定；对决双方可以有不同的既定色彩与材质，不要求全片只有一种能量色。

宏大对决、灾难、兽人世界观与组合特效同样先安排观看重点、角色调度及主次层级。静态构图也可呈现规模和效果，不能一律要求推拉摇移、慢镜或高速旋转。风格特效、镜头奇观与[转场](transitions.md)区分清楚，过场合成不改写剧情中的真实时间和空间。

## 最终检查

效果是否来自材料、宿主与数量是否稳定、路径和作用结果是否有因果、遮挡与发光是否合理、主体和口型是否可读、结束状态是否接续。效果声仅对应实际事件或用户允许的主观表现，不自动配乐。不承诺“一次成功”或固定成功率；文件和文字检查不替代实际生成、物理可信度与风格验收。
