# 剪切与转场

先确认本次改变的是时间、空间、视点还是事件阶段，再决定硬切、连续性剪切、声音桥或有依据的风格转场。没有转换需求时延续当前事件；转场不授权新增过路者、开门、闪光、道具、空镜、对白或时间跳跃。

## 三段衔接

内部依次确定出镜结束状态及对应点、剪切或遮挡发生处、入镜起始状态。最终在两镜正文写清实际对应的动作、形状、方向、光色或声音，并保持人物身份、道具和剧情顺序。转场时长计入实际镜头预算，不附加统一秒数。

| 方法 | 选择条件与执行内容 |
| --- | --- |
| 硬切、反应、视线、动作接续、已有细节与主观镜 | 新画面补充必须看清的信息。明确谁看向谁、接在何动作阶段、何处完整承接；不为反应镜新增行为，不重复演已完成动作。 |
| 运动或遮挡转场 | 两端的运动方向、速度和落点对应；遮挡来自已有物体或人物。区分真实连续运动与在遮挡处剪接，不声称摄影机无切换穿过墙面或实体。 |
| 形状、颜色、构图与动作匹配 | 两端已有对象具有具体对应关系，同时交代时间地点是否改变；不因形似让道具变成另一物体或让角色无故换场。 |
| 光学、移焦、亮暗或黑场 | 用于材料支持的注意转换或时空变化。失焦、过曝或黑场不截断必见动作与对白；闪光、关灯或眨眼不能仅为转场而凭空发生。 |
| 镜面、水面、粒子、故障、翻页、倒放、停格与分屏 | 依据已选风格及用户允许范围采用，写明编辑效果和剧情事件的区别。真实倒影不等于传送，画面倒放不自动等于角色拥有逆时能力；分屏不新增重复实体或未给场景。 |
| 声音桥、声音先入或画面先切 | 声音先入为下场已有声音先于其画面出现；声音后续为上场已有声音延续到下一画面。标明真实声源、起止和所跨切点，不固定提前或延续1至2秒。 |

声音相似匹配、环境尾音、剧情已有静默及用户允许的音乐均可参与衔接。拟音、接触声与其实际动作同步；声音桥不要求所有动作声提前半拍，也不能让主观心跳变成现场扩声。对白跨镜仍属于真实说话人，原句逐字连续；不吞尾音、换归属或为了匹配转场改写对白。

## 模式与连续性

真人剧默认保持空间、受力和光源关系；有依据的剪辑或合成效果可采用，但明确其转换性质。3D漫剧可按已选三维风格使用图形匹配或风格化遮罩，保持模型、空间与材质连续；不自动生成文字、拟声词或另一套画风。已给的停格、静默或固定画面可以保留。

跨轴时先核对用户限制与现有空间信息；需要改变轴线时须让观看关系可理解，不能用转场名称掩盖方位错误。时间跳切保留剧情依据；连续行动的同一时刻则维护道具、朝向、光向、曝光及声音。组界不自动要求新转场、建立镜头或换人物。

没有硬切比例、每分钟转场配额或通用成功率。复杂度影响可读性时先简化可选拍法，并保留原有事件和对白；不通过统一提速或删除动作修复转场。交付前核对出入镜状态及声音，成片是否成立须实际生成后另行验收。
