# 本地运行与隐私

Rui-Skills v2 不需要设备凭证、管理员发放、客户端版本审批或在线制作服务。初次安装下载公开可获取的闭源引擎并核对文件摘要；SHA-256用于完整性校验，不是服务器授权。

制作资料、角色原图和资产在本机处理。实际生图由用户当前选用的图像工具执行；该工具如何处理输入由其自身服务决定，不能将“Rui-Skills不上传图片”说成“任何生图服务都不上传图片”。本地引擎不调用模型API。

云端地址与更新公钥公开在 `evolution-config.json`。指标和生成反馈分别需明确同意；默认关闭。反馈不含自由文本，只接受固定类别。服务仅保留UTC日、功能类别、痛点类别、结果、是否采用增强预设和尝试档位的计数，30天到期清理；在线服务每小时维护，停机后恢复时清理。随机事件/任务ID只在内存短期去重，不进入聚合文件。服务运营者可见请求与连接元数据，不声称端到端匿名。

`node scripts/evolution.mjs disable metrics` 和 `disable feedback` 分别停止以后上报；没有后台队列，不会在关闭后补传。已有聚合按期限清理，无法提取某个人的贡献。`disable updates` 停止更新检查；`rollback` 回退并关闭自动更新。设置保存在当前用户的 `.rui-skills` 目录，制作素材不保存在技能安装目录。

云端异常不阻断本地任务，继续使用本地已验证规则；损坏规则回到内置基线。更新须通过内置公钥验证，只能选择固定规则ID，不能下载执行任意代码。断网不影响制作，但云端反馈与更新需要网络。

当前本地引擎包支持 Windows x64 / Node.js 24.15.0。没有图像工具时仅能提供提示词及资产管理，不能生成真实图片。旧版服务凭证无须导入到此版本。
