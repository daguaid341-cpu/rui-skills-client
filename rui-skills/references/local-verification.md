# 在线授权与隐私

客户端开源，制作服务为私有云服务。安装源代码不自动获得服务使用权；每台设备需要由服务管理员私密发放的凭证。

## 领取与导入凭证

向提供本技能的管理员申请设备凭证文件，通过私密渠道领取；不要在公开 Issue 中填写密钥、凭证文件、聊天或剧情。

从技能目录运行：

```text
node scripts/local-gate.mjs configure-client --from 私有凭证.json
node scripts/local-gate.mjs verify
```

换发后使用 `configure-client --from 新凭证.json --replace`，再运行 `verify`。需要停用、恢复或换发时联系管理员。客户端不能自行发放有效凭证或绕过服务许可。HTTPS必须可信，拒绝重定向；授权或连接失败则停止执行。

Windows凭证使用DPAPI CurrentUser加密并限制文件权限，其他系统使用0600文件权限。账户内恶意程序仍可能取得凭证。原始导入文件包含秘密，确认导入后应妥善清除传输副本；泄露时立即联系管理员换发。禁止将任何凭证提交到仓库。

## 数据用途

授权请求包含设备标识、凭证及客户端版本，不含剧本。在线制作会发送用户选定的JSON及明确选择的原文、模式和参数；单次最多2MiB，图片不会自动上传。服务按请求处理制作资料，不将正文写入使用指标或训练集，不调用第三方模型。

必要安全审计包含时间、设备ID、操作类别、状态和耗时，不含凭证、剧情、输出、路径或IP。服务运营者仍能接触请求内容和连接元数据，不能声称端到端匿名。用户不允许发送制作资料时无法使用在线制作。

用于改进提示的使用指标为单独可选项，默认关闭，拒绝不影响服务；同意范围、保留期限和关闭命令见[记录与复盘](learning-loop.md)。安全认证与审计不受此可选开关影响。

开源范围是客户端和公开数据契约，不包含云端制作核心、私有部署配置、管理员工具或旧仓库历史。开源许可不授予云服务访问权。已经交付的结果无法远程收回。
