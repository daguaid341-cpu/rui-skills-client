# 竖屏取景与摄影实务

在[叙事设计](narrative-camera-design.md)确定观看重点之后使用本库。拍法只组织已有内容，不新增人物、环境、道具或事件。术语和引擎枚举查[摄影术语](cinematography-vocabulary.md)，风格边界查[模式](mode-profiles.md)。

## 取景范围与竖屏层次

景别名称后补足实际裁切：牛仔景通常至大腿中部，膝上、腰上、胸上、肩上、完整面部与局部各自容纳不同动作。坐姿、俯身、递接和持物时重新检查实际范围；不让约定称呼代替画面边界。全景、远景可用于全身动作、距离和规模，不因室内或后续组而禁止。

9:16画幅可用前后错位、前景肩背、纵深及高低层次呈现多人关系。前景面积以不遮挡关键嘴部、眼神和接触点为准；重要后景事件保持可辨。实际路线横向经过画面时可侧随、横移或固定观察，不强制改成朝摄影机走。用户要求保留的宽空间关系可用合适景别呈现，不虚构场景窄化。

按实际发布界面检查重要面部、道具与已有文字是否被裁切或界面遮挡。没有目标界面资料时保留合理边缘余量，不编造固定安全区百分比、字幕栏或平台图标。

## 视点与介质画面

| 情况 | 画面须明确的内容 |
| --- | --- |
| 客观观察、过肩与主观视点 | 摄影机属于何种观看位置；过肩是谁的肩、拍向谁；主观镜属于谁、看向何对象。角色通常看剧情对象，不能默认直视摄影机。 |
| 镜子、玻璃、金属、水面倒影 | 本体与反射面的位置、可见反射范围、遮挡及观看方向相容。反射不产生另一名实体；反射面必须已存在。 |
| 手机前后摄、屏幕、监控画面 | 区分拍屏幕本体、画面内部视点与切成满屏影像；来源设备和内容须有依据。不自动添加日期、水印、字幕、界面或记录指示。 |
| 材料已有的醒来、眩晕或视线变化 | 主观模糊、倾斜、清晰恢复与已有感知变化对应；不能借摄影效果新增昏迷、回忆或幻觉。 |

梦境、回忆、想象或说辞可视化先核对材料是否确立其性质与内容；不能把人物谎言或未经证实的经历拍成客观事实。

## 焦点与观看顺序

焦点落在本阶段的必见信息：面部镜保持必要眼神和口型，接触镜保持动作落点，证物镜保持既有证据，后景事件发生时让其确实可读。面部不必在所有镜头中最亮最清楚。

移焦写清开始清楚的对象、触发、转移对象与结束状态，演员的动作和对白保持原顺序。景深由焦距、光圈、对焦距离及空间关系共同影响，不能用固定大光圈覆盖所有关系镜。焦点转移、变焦和摄影机位移分别描述；镜头呼吸是对焦伴随的视角变化，不等于失焦搜索、呼吸声或手持晃动。

## 组合运动与节奏

基本运动可按已有行动分段组合，例如随行后停稳观察、摇向已有对象后推进。逐段写清触发、起止取景、路径、速度和焦点，先核对空间与人物动作，再核时；不为让摄影机完成复杂运动增加人物等待。稳定方式另选，固定、手持、肩扛或机械稳定均无配额和额外审批。

快速摇摄、旋转、倾斜、升降、俯视、贴地或贴物取景按本镜信息采用。路径不穿过既有实物，复杂运动不遮掉所需口型与动作。镜头速度与人物速度可以不同，必要时明确相对关系；不采用统一加速或动作幅度缩减比例。

## 现有光源与场景条件

逐场明确方向、软硬、冷暖及局部亮度关系。窗口、门缝、屏幕、烛火、车灯、霓虹、水面反光、树影等只有在材料或真实参考已有时才选用。人物与光源移动时，照亮区域、衣料反光、遮挡和影子随位置连续变化；眼神光也应来自实际可成立的反射，不给所有眼睛加同样亮点。

夜窗、走廊、雨街、空房、门口、餐桌与楼梯等仅是查询情境。使用其已有光源、距离和声场设计，不能附带模板中的雨、雾、时钟、餐具、车辆或围观者。场景不因“电影感”统一变成冷暖对撞、金色广告光或强逆光。细则继续执行[光影与声音](storyboard-pacing.md)。

## 跨镜状态简记

内部维护当前有效状态，变化后更新即可：在场角色及朝向、场景坐标、观看关系、坐站姿态、道具归属与接触、服装和既有湿损状态、门灯等已有物件状态、光源与声源。保留叙事相关后景人物，不因切镜消失或复位。没有伤口、湿发、扣子变化等依据时不添加。每组起点承接真实末态，分组本身不要求建立镜头、换主体或重演。
