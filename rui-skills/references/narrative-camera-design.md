# 叙事镜头设计

真人剧与漫剧排镜前读取本文件，再按[节奏与连续性](storyboard-pacing.md)安排时长，按[提示词输出规则](prompt-output.md)整理最终文本。镜头设计由助手依据用户材料完成；引擎校验字段和导出文本，不能替代导演判断。

## 先定功能，再选拍法

每镜先明确观众必须看见的信息：空间关系、对白交锋、已有反应、信息暴露、道具证据或权力关系变化，再选择景别、拍摄方向、拍摄关系、构图、焦点和必要运镜。内部可在已有 `cut.note` 中简记功能与对应节拍，保留原有备注；不新增引擎不支持的必填字段，不把审核说明复制到最终提示词。

分别设计四个维度：景别决定看见多少；机位角度决定从哪里看；拍摄关系决定双人、过肩、单人正反打或细节插镜；运镜决定摄影机是否移动。平视可以用于侧面、斜侧和过肩，固定镜头也能形成正反打。人物之间的平视属于行为和视线关系，不自动等于摄影机平视正面。

禁止用循环或模板把全场默认填写为“角色名＋平视”“Static Shot”“中心构图”，也不按景别机械决定全部焦距与光圈。允许同一拍法连续出现，但应有叙事理由；不设仰拍、俯拍、运镜、特写或正反打的数量配额，不按人物身份固定分配强者仰拍、弱者俯拍。不为丰富镜头新增剧情节拍、重复反应、停顿或时长。

重用既有制作脚本时先审查字段填充逻辑；带有上述统一默认值的旧脚本不能直接套用。逐镜显式传入已设计的摄影字段，缺少设计时先完成排镜，不以通用值静默补齐。

## 景别与侧面方向的组合

景别和机位方向分别选择，再组合写入镜头正文。侧面不只用于某一档景别；在已知空间与人物朝向允许时，可作如下取景：

| 景别 | 侧向取景所呈现的信息 |
| --- | --- |
| 大远景 | 从侧向交代环境与人物在空间中的关系 |
| 全景 | 从侧面呈现全身姿态与完整动作 |
| 中景 | 从侧面呈现上身动作、交流和视线关系 |
| 特写 | 从侧面呈现已有面部表演或关键动作、道具细节 |
| 大特写 | 从侧向呈现承担明确剧情信息的眼部、嘴部或局部细节 |

这些是可选择的组合，不是每个景别另配一镜的清单。逐镜写清被摄者姓名、人物面向与视线对象、摄像机相对人物的方向及取景范围；区分严格侧面与斜侧，不只写“中景”“特写”而省略必要方向。人物朝向与摄像机方向须在同一空间中成立，不能为了凑侧面镜头新增转头、转身、走位或重复表演。

## 超过30秒任务的跨组景别

本节为用户于2026年10月15日明确指定的生成规则，适用于同一次连续剧情分镜任务总时长超过30秒、需要多个分镜组的情况：

- 首个分镜组优先用全景、中景交代已有空间、人物关系与动作；“多用”不规定比例，也不强迫每镜都使用这两档景别。
- 从第二组开始，各后续组均不得使用全景或中景，包括对应的侧面、斜侧、双人及过肩取景。不能通过改变角度、运镜或景别标签绕过禁用；`size`、`frame`、`shot`及最终取景必须一致。
- 后续组依据本组已有信息选择特写、大特写等合适取景。需要近距离呈现时，在现有景别字段支持的范围内明确实际取景，不新增引擎不支持的枚举，也不把实际中景改称特写。其余景别仍按叙事功能选择，不为变化增加镜头或剧情。
- “30秒组”仍是每组上限30秒、按实际对白和动作自然分组；不要求首组填满30秒，不将本节改成固定时长。总时长不超过30秒的任务不触发“后续组禁用”。
- 按同一次连续任务的实际组序判断首组，续写、单独导出后续组或因视频工具上限再拆批时不重新获得首组资格；换场本身也不自动解除后续组限制。若原文必要动作或空间信息确实无法在限制内完整呈现，先提出最小必要问题，不自行恢复全景、中景或删去剧情。

内部记录组序与景别限制；每组独立交付时，将本组确实适用的关键限制写清，不依赖生成AI收到其他组。首组和后续组都保留原台词、已有动作、人物实名及真实素材引用。

## 对话覆盖与正反打

用户于2026年10月15日明确选择以下对话机位逻辑：在同场画内对话中，讲话者面向被讲话者，视线落向对方；人物朝向和摄影机朝向分别描述，不把人物默认摆成面对摄影机讲话。沿用材料已确定的姿态、位置与视线；材料明确背向交谈、电话或画外声音时按实际关系处理，不为套用常规对话构图新增转头、转身或走位。

以当前讲话者与被讲话者之间的视线连线为对话轴线。拍讲话者时，摄像机从被讲话者所在这一端朝讲话者取景，可在轴线同一侧偏移，形成过肩或斜侧单人镜头，不要求摄像机严格压在两人视线连线上。反打拍另一人时，切换到对应人物对面的端点，摄影机仍保持在已经建立的轴线同侧，保留视线对应与人物方位；不能仅因说话人更换而越轴。拍听者已有反应时，从讲话者这一端拍向听者，画外台词仍归实际讲话者，听者不对口型。

过肩时写明被讲话者的哪一侧肩部处于前景、镜头拍向哪位讲话者；斜侧时写清从被讲话者这一端偏向哪一侧取景，具体左右依据已知空间确定，不填入未知方位或固定角度。严格侧面须在实际人物朝向与机位关系允许时使用，不能把沿听者端偏轴拍摄机械写成90°侧面。多人物交锋按本句实际被讲话者确定当前轴线，发言或视线对象改变时保留已有先后顺序，并让轴线衔接可理解。所有方向选择同时服从本任务适用的跨组景别限制，不因采用过肩或斜侧重新获得全景、中景。

依据既有场面关系选择双人镜头、过肩、斜侧单人镜头及对应反打。台词轮换不等于每句必切；在同一镜能清楚呈现的动作与对白可并行。反应镜只承接材料已有反应，不编造听者小动作，也不把画外对白变成听者对口型。

逐镜明确被摄主体、前景人物、人物看向的对象和轴线关系。过肩镜要写清谁的肩在前景、镜头拍谁；正反打保持可理解的视线对应和人物方位。三人以上交锋中，发言对象改变或新人物进入时，按需要用关系镜或已明确的取景交代空间，再转入对应人物，不机械给每人一个正面特写。

在用户材料及实际查看的参考素材已明确的空间关系内选择机位。不能为了架设正反打新增人物走位、指定未知左右手、让角色转身或移动道具；不可虚构已经查看的参考布局。任务确实需要而材料未明确的站位、手位或衔接，先提出最小必要问题，不猜出答案。

## 功能性面部特写

特写须放大当前节拍已经存在的信息，而不是只写“情绪强烈”“眼神复杂”。可以表现材料中的说辞受阻、自嘲、目光锁定、既有视线变化、张口无言或僵住等；具体用途取决于当前剧本，不将这些表现当作固定动作清单。

以用户提供的剧情和人物小传理解当下情绪、眼神与语气，只细化已有行为的表现。特写不授权新增眨眼、吞咽、咬唇、抿嘴、握拳、流泪、后退或接触；材料未给出的行为不能为增加微表情而补入。不得用生理变色表现情绪，不新增人物已知信息，不提前呈现后续真相，不把人物说辞拍成真实回忆。

说话面部特写通常保留眼睛与嘴部，保证表演及口型可辨。眼部、嘴部大特写只有在该部位承担明确且已有的信息时才使用；不能把一句完整对白机械拆成多个五官插镜。取景改变不改变台词、说话者、动作对象或先后顺序；视线依次看向多人时保留具体姓名和完整顺序。

需要同时看清面部与手中道具、双人接触或视线落点时，选择能容纳这些信息的景别和景深，不强行裁成孤立面孔或把证据虚化。既定摄影基准按用户要求保留，实际单镜参数保持自洽，按动作和信息清晰度选择焦距、光圈与焦点。

## 写入资料并保留到最终输出

在现有 `size`、`camera`、`cameraPosition`、`composition`、`eyeline`、`focus`、`lens` 和 `stability` 中落实镜头设计，并同步 `frame`、`shot` 与使用中的协议描述。必要方向、前景人物、反打对象和功能性取景范围写入镜头正文，避免导出后丢失；只填写模板字段不算完成设计。

最终逐镜用实际角色姓名写清拍谁、从哪里拍、看向谁，以及需要看清的动作或信息。精简稿保留影响叙事的机位、过肩与反打关系、视线顺序、关键焦点和取景范围，不用统一“平视”覆盖，也不依赖另一组提示词解释当前机位。与本组真实提交的参考素材配合，不虚构绑定或已查看状态；对白及声音继续执行独立可用要求。

## 交付前复核

- 每镜的功能是否实际体现在取景、焦点和切点中；是否只有景别标签而没有拍摄关系。
- 整场机位、构图和运镜是否被模板批量复制；重复拍法若成立，保留其理由，不为通过审核强制增加变化。
- 景别与人物朝向、摄像机方向是否分别写清且相互成立；侧面或斜侧取景是否有必要信息，而非追加动作。
- 超过30秒的连续任务是否正确识别首组；后续组的字段、正文和最终提示词是否仍出现全景、中景或用其他标签伪装这两档取景。
- 正反打的主体、前景、轴线和视线是否对应；三人以上交锋能否辨认谁对谁说话。
- 台词镜头的讲话者是否面向本句被讲话者；拍讲话者的摄像机是否从被讲话者这一端取景，过肩或斜侧与既有轴线同侧；反打及反应镜是否保持方位、说话归属与口型正确。
- 特写是否仅表现已有动作和当下情绪；是否新增反应、泄露信息、改动对白或遮掉关键道具。
- `frame`、`shot`、摄影字段及最终导出是否一致；每组单独提交后能否理解拍摄关系和动作顺序。
- 切换是否重复动作、拆坏完整对白、破坏连续性或拖长节奏。检查文本与程序结果，不将其称为实际配音或成片视觉验收。
