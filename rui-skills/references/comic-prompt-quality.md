# 漫剧提示词质量

`mode=comic` 的成稿按[模式规则](mode-profiles.md)使用3D动画或风格化三维CG，按[3D七字段模板](comic-3d-template.md)交付。本文件保留公开版的动画、声音和实际导出检查；叙事、空间、对白与时长执行[叙事设计](narrative-camera-design.md)。

## 画风与中间稿

保持实际已选的3D造型、模型比例、材质、服装、尺度及资产版本。`production.style` 填具体3D画风，各独立段的 `segment.unifiedPrompt` 写清本段模型、材质、环境光与声音，避免旧项目级真人提示词覆盖漫剧模式。虚拟摄影的焦点、透视、遮挡与景深服务观看重点，不默认追加真人毛孔或多套机身。

编译引擎仍为2.0.1，底层comic默认偏二维，显式三维也可能残留“线条、色板、上色”等通用词。这是中间导出局限，不是现行二维输出分支。交付前按实际3D画风清理并整理七字段；不能声称引擎已自动完成该模板。二维参考只用于身份、轮廓和配色的3D转译，不假称已有3D资产。

## 动画与声音

先确定本镜必须看到的变化，再落实已有动作的起点、过程、接触点和结果。检查肢体交叠、前后遮挡、模型形变和物件接触。交接明确原持有人、接稳与松手时机，只演一次；推近静态表情不代表完成交接、开门或转身。未知但必需的手位或站位先询问。

可选 `cut.animation` 写已有动画过程，`cut.visualTreatment` 写本段3D局部处理；两者进入Rui文本导出，但不能假定所有底层协议都携带。下游必需内容同步到 `cut.shot` 并检查实际导出，不只写“动作自然流畅”。

有限形变、残影、速度感及冲击停留仅在实际3D风格支持且服务已有动作时采用，不增添实体人物、攻击、伤口、反应或剧情。默认无字幕、气泡、拟声文字、分格及BGM。对白写实名、对象、语言、完整原词与语气，画外声注明来源，非说话者不对口型。动作声写具体声音及触发时机，不只写“保留现场声”。

## 导出检查

逐段阅读实际导出，不以JSON校验替代成稿审阅：

1. 3D表现方式具体一致，无二维默认词或真人模板，七字段均有本镜实际内容。
2. 角色与声音用实名。只有script/storyboard时可能保留C01等编号；依已知映射补全，不猜姓名或场景。
3. 动作、持物、末帧及下一段起点一致，不因分组重演动作，不按组序限制全景或中景。
4. 完整对白与已有动作能在所列估算时长内完成；必要时延长镜头并自然分组，不删词或加速。30秒为每组上限。
5. 机位、焦点、光影、声音和素材在本组内明确，不依赖未随组提交的材料。

文本审阅、引擎结构、实际配音和视频验收分别报告。未生成并查看视频时，不能判定画风、口型、运动或人物一致性已通过。回归测试是合成输入；底层二维兼容用例不是最终3D提示词示例。
