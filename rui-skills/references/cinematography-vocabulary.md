# 景别、运镜与拍摄术语

本文件补足已有术语清单的定义、易混区别及落稿方式。术语按当前剧情和人物表演需要选用，不构成必须用完的镜头菜单；不得为使用某种拍法增加剧情、动作、道具或时长。原始对白、人物实名及对话轴线要求继续适用；按[无固定模板的排镜原则](narrative-camera-design.md#镜头排布不采用固定模板)逐镜选择拍法，并遵守用户当前明确的取景要求。

## 景别与取景范围

| 术语 | 实际范围与使用依据 |
| --- | --- |
| 特写 Close-up（CU） | 以面部或已有物体细节为主要画面，突出本镜需要读到的表情、接触或证据信息；明确实际取景，避免裁掉必要口型与动作。 |
| 大特写 Extreme Close-up（ECU） | 只取眼睛、嘴部或物体等更小局部，仅在该局部承担已有叙事信息时使用；不把完整对白机械拆为五官插镜。 |
| 中景 Medium Shot（MS） | 常取人物腰部以上及部分背景，容纳对话、上身姿态和手部动作；具体裁切随姿态与信息需要说明。 |
| 全景 Full Shot（FS） | 完整容纳人物从头到脚及必要环境，呈现全身姿态与完整动作；不是必须交代整个场景的所有内容。 |
| 远景 Long Shot（LS） | 人物在较大环境中所占比例较小，强调距离、规模及人与空间的关系；不能只凭拍摄距离或长焦镜头名称判断。 |
| 极远景／大远景 Extreme Long Shot（ELS） | 环境占主导、人物很小或不可辨，交代大尺度空间；仅使用材料已提供的场景，不为建立空间补造城市或风景。 |

中英文景别在不同制作体系中可能重叠，Full Shot、Long Shot等名称不能替代具体取景范围；提示词写清主体占比、必要裁切与环境关系。定义核对见[Adobe景别说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles.html)。

内部 `size` 保留现有五档：`extreme-wide`、`wide`、`medium`、`close`、`extreme-close`。极远景与大远景共用 `extreme-wide`，不新增第六档；远景按实际环境占比及取景如实归入已有档位，并在 `frame`、`shot` 与最终正文明确“远景”及其范围。景别名称须对应实际取景，不能通过改名规避用户明确要求。

## 摄影机运动

| 术语 | 运动方式及写法 |
| --- | --- |
| 推 Push In／Dolly In | 摄影机实际向主体靠近；写明拍谁、从何范围推进至何范围以及动作或情绪落点。 |
| 拉 Pull Out／Dolly Out | 摄影机实际远离主体，逐步显露材料已有的空间关系；写明起止范围，不借拉镜新增场景或人物。 |
| 摇 Pan | 机位位置基本不变，向左或右水平转动观看方向；写明从谁／何处摇向谁／何处，不能与横向位移混写。 |
| 移 Truck／横移 | 摄影机向左或右实际平移，改变前后景相对关系；写明移动方向及沿途需保留的主体、接触点与轴线。Dolly Shot泛指移动平台拍摄，不专指横移。 |
| 跟 Follow Shot／Tracking Shot | 摄影机随材料已有的移动主体行进，可在侧面、前方或后方跟随；主体未移动时不能为“跟拍”新增走动。 |
| 升降 Crane Up／Down | 摄影机高度实际改变；吊臂可产生带弧线的升降路径。区分机身整体升降与固定机位只改变俯仰方向的 Tilt，不将两者混称。 |

推拉是位置变化，变焦 Zoom 是焦距变化；需要两者组合时分别交代。摇摄与横移、升降与俯仰同样分别表达，不能只写一个含混的“镜头移动”。各运动写明必要起点、终点、方向与节奏，运动途中也遵守当前组允许的取景。核对见[Adobe推拉与跟拍说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/tracking-shot.html)及[摇摄说明](https://www.adobe.com/creativecloud/video/production/cinematography/camera-shots-and-angles/pan-shot.html)。

`camera` 使用[现有协议枚举](novel-storyboard-schema.md)，如 `Push In`、`Pull Out`、`Pan Left/Right`、`Truck Left/Right`、`Tracking Shot`；具体左右方向写入正文。纯机位升降可用 `Pedestal Up/Down`，只转动俯仰用 `Tilt Up/Down`。吊臂及其他组合运动如实选择能表达主运动的允许值，在正文补全路线与顺序，不把 `Crane Up/Down` 或 `Dolly In` 等别名直接新增为枚举，也不把运动填写为固定。

## 光线与色彩

| 术语 | 含义与执行边界 |
| --- | --- |
| 高光 Highlight | 画面中物体较亮的区域或反光；保留材质与柔和过渡，不等于所有高光都应过曝或纯白。 |
| 阴影 Shadow | 直接受光较少或被遮挡的区域，仍可获得环境与反射光；按叙事需要保留暗部细节，不等于无细节的死黑。 |
| 背光 Backlight／逆光 | 光从主体背面方向照来，可分离轮廓；是否形成明显轮廓或剪影取决于已有光照关系，不自动增加一盏轮廓灯。 |
| 侧光 Sidelight | 光从主体侧方照来，以受光面和阴影面塑造体积；不因摄影机换位随意改变场景光源方向。 |
| 色温 Color Temperature | 以K表示光色冷暖的度量；一般光源低色温偏暖、高色温偏冷。场景光源色温、摄影机白平衡与后期调色分别考虑，材料未给出时不编造精确K值。 |

色温及白平衡的区别可核对[Nikon白平衡说明](https://onlinemanual.nikonimglib.com/zr/en/18-06.html)。具体光照关系与跨镜曝光按[光影效果统一规则](storyboard-pacing.md#光影效果统一规则)执行；以上术语不能代替本组实际光源、受光与冷暖关系，也不把夜景参考强加给其他场景。

## 连续性、剪辑与摄影稳定方式

- **连续性拍摄 Continuity Shooting：**使不同镜头在动作阶段、视线、方位、道具状态和声音上能够连贯剪接；不等于必须一镜到底或按剧情顺序实际开机拍摄。具体检查执行[连续性复核](storyboard-pacing.md#连续性复核)，不重复表演已完成的动作。
- **蒙太奇 Montage：**通过镜头组合组织时间、空间及信息关系，可压缩过程或形成并置意义，并不限定必须跨越不同时空。仅组织用户已经提供的内容；不能借此新增回忆、经历、象征性道具、人物知识，改变已有因果，删改原始对白或遗漏关键动作。原文包含明确时间／空间跳转时，在每组独立提示词中写清实际关系，不默认增加BGM。术语参考[牛津研究档案中的蒙太奇论述](https://ora.ox.ac.uk/objects/uuid%3A11e683e9-3526-4a4d-bfd9-7681ee0a6c72/files/s8336h432m)。
- **手持摄影 Handheld Camera：**以手持方式形成贴近现场的运动感，晃动程度服从当前信息与表演；不等于必须强烈抖动。与已有“轻微手持晃动”规则配合，不能使必要口型、表情和接触点失去可辨性。
- **斯坦尼康 Steadicam：**用于平稳移动的摄影机稳定系统与相应拍摄方式，不是所有稳定器的统称。按需要写“斯坦尼康平稳跟随”等实际效果；未指定设备时可直接写“稳定器平稳移动”，不虚构已经使用具体设备。系统含义见[Tiffen官方说明](https://tiffen.com/pages/steadicam)。

运动轨迹与稳定方式分别选择：跟拍可以手持或稳定拍摄，固定取景、轻微手持感和画面冻结继续依[摄影术语与运动状态](narrative-camera-design.md#摄影术语与运动状态)区分。`stability` 仍使用已有 `stable`、`slight-shake`、`handheld`，蒙太奇在镜头组合和正文中表达，不新增引擎枚举或必填字段。最终提示词只保留本组实际选用的术语及具体画面，不附整张词表或内部字段说明。
