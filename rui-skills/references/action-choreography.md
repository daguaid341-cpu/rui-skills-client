# 动作与打斗镜头

用于材料已经给出的动作、追逐和打斗的影视呈现，不生成新招式、攻击、伤害、敌人或场景破坏。先依[叙事设计](narrative-camera-design.md)确定观众需要理解谁对谁、何时发生什么，再选择取景、运动与切点。以下是画面组织条件，不是现实格斗操作指南。

## 动作的因果过程

把已有动作连成可辨过程：起始姿态与方向、动作路径、接触或避开、材料已有反应、结束与承接。准备、反击和恢复仅在材料给出或同一动作本身必需的连续过程内呈现，不借完整动作链增加一轮交手。

核对重心、支撑、重量、惯性与接触方向。动作主体、承受者、持物归属、接触处及之后的位置明确，身体、服装和道具不穿透。受击、落地、承托、脱离与声音有因果关系，不采用统一延迟半秒或先出撞击声再接触的模板。

## 按已有动作选取景

| 动作类型 | 镜头需要读到的关系 |
| --- | --- |
| 徒手、腿法、身法、防守与闪避 | 谁发起、谁回应，方向与距离怎样改变，接触或避开的结果；全身或局部按动作信息选择，不强制每个接触点特写。 |
| 冷兵器、暗器、枪械与其他既有道具 | 道具属于谁、运动起点与方向、材料已有的命中或落点及后续状态；不补加弹药、伤口、血迹、装填或新武器。 |
| 追逐、跑酷、摔投与地面动作 | 路径、既有障碍、支撑和落点、人物前后关系；镜头运动与真实路线相容，不为刺激效果添加跳跃、坠落或危险物。 |
| 多人混战与连续组合 | 各参与者的位置、目标及实际先后，重要旁观或被保护角色的位置；不靠复制角色填满画面。连续动作可同镜成立，也可在有意义的节点切换，不规定一镜一招。 |
| 终结、异能、场景破坏与巨型对抗 | 只呈现原材料给出的结果和规模，明确攻击来源、路径、作用对象及已有反应。查[特效](visual-effects.md)，不能将招式名自动扩写成毁楼、爆炸或群体伤亡。 |

已有连续动作中，适时用关系取景交代方向和距离，用近景呈现必须读清的接触或表情，再从真实末态承接；不是每场必须使用的镜头顺序。摄影机可以固定、跟随或转换取景，不要求所有动作镜头持续运动，也不按出拳次数机械切镜。

## 真人剧与漫剧

真人剧按既定风格维持重量、身体结构、服装与接触，允许材料已有的超现实动作，但其视觉过程和结果仍需清楚。漫剧按既定造型组织关键姿态与连贯方向；有限形变、残影、速度线或冲击停留须符合已选风格，只强调已有动作，不增加招数、分身或命中。

慢动作、停格和变速只有在用户要求或既定表现风格支持时采用，并计入实际播放时长；不为填满组时长加入。运动模糊、粒子和光效保留必要身体与落点的可读性，不用晃动掩盖动作缺步。

## 声音与验收

脚步、衣料、已有道具运动、接触和落地声对应实际触发与材质，远近随位置变化；没有开枪、破碎或伤害就没有对应声效。对白仍完整，动作并行按真实可重叠部分计时。

交付前核对人物数量、攻击对象、方向、接触、重心、道具、结果和末态；场面过密时调整取景或在自然节点分镜分组，不删事件、不新加动作。文本和结构检查不能证明实际视频接触可信，成片动作另行验收。
