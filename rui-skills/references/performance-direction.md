# 表演与对白调度

以用户提供的剧情、人物资料与当前知情范围解释表演。表演库用于选择怎样呈现已给情绪和行为，不能从情绪词自动生成新动作、道具或经历。声音和时间继续执行[节奏与连续性](storyboard-pacing.md)。

## 表情的发生过程

写清已有状态、触发节点、变化及结束状态，按本场需要选取眉、眼睑、视线、鼻翼、嘴唇、下颌或已有姿态中的可读变化。不要每项齐写；幅度可细微、清楚或强烈外露，服从人物与事件，不把全部表演压成微表情或强制爆发。

| 已有情绪或过程 | 表演设计关注点 |
| --- | --- |
| 喜悦、笑意、压住的笑或笑泪 | 笑意如何出现、持续或被控制；笑与泪只有材料同时给出时才并行，不把笑改成另一段哭戏。 |
| 难以接受、悲伤或恐惧 | 获取信息的时刻、目光和嘴部变化、声音与既有气息如何接续；没有流泪、后退或颤抖依据时不自动添加。 |
| 愤怒、厌恶、轻蔑、怀疑 | 明确所针对的人或内容，选择已有表情的强弱和持续范围；不靠握拳、摔物或新增威胁证明情绪。 |
| 镇定、控制、掩饰或胜券在握 | 表面节奏、眼神与台词语气保持人物当下策略；台词字面和面部情绪可以有材料支持的反差。 |

不将某个看向方向、手势或表情当作测谎和心理诊断公式，不以性格标签或性别替代实际人物设定。禁止用眼睛、眼眶、脸色、皮肤或指节等生理变色表达情绪；真实造型颜色与已有光源造成的受光变化按其本来原因描述。原始对白措辞保持不变。

## 说话与倾听

讲话者、听者和旁观者分别维护视线、口型与已有反应。可以在讲话者、关系镜或听者画面中承接同一段声音；听者不对讲话者的台词口型，不因需要反应镜而新增点头、吞咽或转身。

把语气、重音、气息和材料已有停顿对应到本镜确实列出的短语或动作节点，在台词前的说明或画面正文写明，不往原句插斜线、改标点、拆改词序。原文已有抢话、重叠、结巴、重复、欲言又止、哽咽或开口失败时，标清发起者、发生处和声音接续；没有这些内容时不为了“自然对话”添加。

对白的外露情绪与人物的控制可以同时存在，依据人物资料确定何处泄露、何处克制。不能规定所有字词、表情与内心必然一致，也不把推断出的潜台词写成新增台词或事实。

## 气息与声音

呼吸、颤息、笑声、哭声和声音沙哑按本场已有要求安排起止、强弱和与对白的重叠。急促沉重的呼吸可以与难以接受的表情同步，不必另切胸口或嘴部。若材料要求话筒拾取，明确人物与实际话筒的距离和拾音关系，再写现场扩声；没有合理拾取条件时不凭空增加第二支话筒或贴身麦。

主观心跳、音乐和场内声音分别说明。用户明确允许的心跳只在其指定情境使用，写清进入、持续与退出，不自动通过宴会音箱播放。不同角色的声音节奏可以形成对比，各自保持本场设定；不让旁人随主角情绪一起急促。完整对白仍优先清晰，不靠音效掩盖口型和词尾。

## 既有身体行为与特殊角色

醒来、递接、搀扶、拥抱、同行或恢复等行为仅在材料已有时组织，写清对象、接触与完成状态；不把行为库当作剧情补写器。手位未知但不影响动作可读时无需追问，确实影响接触和连续性时先最小化询问。

非人角色仅使用其实际参考已有的耳、尾、口鼻、须毛、爪或其他结构。脸部变化和已有肢体动作相协调，附属结构的运动服从造型、材质和受力，不把动物器官加给真人或让人耳执行不成立的表情动作。真人生物与3D漫剧角色分别保持[模式](mode-profiles.md)和资产比例、辨识特征及版本。

3D漫剧具体执行[表演与微动态](comic-3d-template.md#3d表演与微动态)：主体情绪可较外放，幅度仍服从已有剧情和人物；眼、口、面部组合及呼吸微动态按需选用，不套固定数值和次数，不从模板添加新动作。

## 成稿检查

表演说明是否有实际触发、对象和变化；说话人、口型、语气及声音来源是否一致；复合情绪是否来自材料；是否夹带动作库中的新行为；重要变化在当前取景是否可读。已有眨眼等微动作按剧情自然发生，不设次数、幅度或镜头配额。文本核对不代替实际配音和表演验收。
